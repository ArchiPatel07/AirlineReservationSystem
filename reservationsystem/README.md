# Airline Reservation System
A Java console application to manage flights,passengers,and bookings,built using core  OOP principles.
## Features
- Add and view flights
- Book tickets with seat availability checks
- Cancel bookings
- Save booking records to a file
- Custom exception handling for full flights
## Technologies Used
1. Java 21
2. Maven
3. Collections (ArrayList)
4. File I/O
## Classes
- `Person`(Parent class)
- `Passenger`,`Admin`(extend Person)
- `Flight`
- `Booking`
- `SeatNotAvailableException`
- `ReservationSystem`(core logic)
- `App`(main menu)
## How to Run
1. Clone this repository
2. Open is VS Code with Java Extension Pack installed
3. Run `App.java`
4. Follow the on-screen menu
